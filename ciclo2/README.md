# Fixtures del ciclo 2 del plan de pruebas

Páginas con errores de accesibilidad **intencionales** para ejecutar los casos de flujo completo
del catálogo v3.0 (`faro-ecosystem/context/plan-pruebas.md`). Cada página es un sitio aparte en
FARO. Ids, clases y nombres llevan el prefijo `c2-` para que el locator de la fuente no encuentre
coincidencias en otros archivos del repositorio.
